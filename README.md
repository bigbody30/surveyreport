# รายงานเยี่ยมร้านค้าเทียบแผน

เว็บแอปสำหรับอัปโหลดไฟล์ Excel 2 ไฟล์ (แผนเยี่ยม + เยี่ยมร้านค้าจริง) บันทึกลง Supabase
แล้วสรุปเป็นรายงาน Excel ว่าร้านไหนเยี่ยมตามแผนแล้ว ร้านไหนยังไม่เยี่ยม และร้านไหนเยี่ยมนอกแผน

ทำงานเป็นเว็บไซต์ static ล้วนๆ (HTML/CSS/JS) ไม่มี backend server ของตัวเอง —
เบราว์เซอร์จะอ่านไฟล์ Excel และคุยกับ Supabase โดยตรง

## 1) สร้างตารางใน Supabase

1. เข้า [supabase.com](https://supabase.com) เปิดโปรเจกต์ของคุณ (หรือสร้างใหม่ ฟรี)
2. ไปที่เมนู **SQL Editor** > New query
3. คัดลอกเนื้อหาทั้งหมดในไฟล์ `supabase-schema.sql` วางแล้วกด **Run**
4. จะได้ตาราง 3 ตาราง: `upload_batches`, `visit_plans`, `actual_visits`

## 2) ใส่ค่าเชื่อมต่อ Supabase

เปิดไฟล์ `config.js` แก้ 2 บรรทัดนี้ให้เป็นค่าของโปรเจกต์คุณ (หาได้จาก
Supabase Dashboard > Project Settings > API):

```js
const SUPABASE_URL = "https://xxxxxxxx.supabase.co";
const SUPABASE_ANON_KEY = "eyJhbGciOi....(anon public key)....";
```

> ใช้ **anon public key** เท่านั้น (ไม่ใช่ service_role key) เพราะไฟล์นี้รันในเบราว์เซอร์ฝั่งผู้ใช้
> schema ที่ให้มาเปิด RLS แบบอนุญาต anon key อ่าน/เขียนได้เต็มที่ เหมาะกับใช้ภายในทีม
> ถ้าต้องการจำกัดสิทธิ์เพิ่ม (เช่น auth คนใช้งาน) ปรับ policy ในตารางภายหลังได้

## 3) ทดสอบก่อนดีพลอย

เปิดไฟล์ `index.html` ตรงๆ ในเบราว์เซอร์ได้เลย (ดับเบิลคลิก หรือ `File > Open`)
หรือรันเซิร์ฟเวอร์เล็กๆ ในโฟลเดอร์นี้ เช่น:

```bash
npx serve .
# หรือ
python3 -m http.server 8080
```

## 4) ดีพลอยขึ้นเว็บจริง

อัปโหลดทั้งโฟลเดอร์นี้ขึ้นโฮสติ้ง static ที่ไหนก็ได้ เช่น:

- **Netlify**: ลาก-วางโฟลเดอร์ที่หน้า Netlify Drop (https://app.netlify.com/drop)
- **Vercel**: `vercel` ในโฟลเดอร์นี้ (ต้องติดตั้ง Vercel CLI ก่อน)
- **GitHub Pages**: push โฟลเดอร์นี้ขึ้น repo แล้วเปิด Pages ใน Settings

ไม่ต้อง build อะไรเพิ่ม เพราะเป็น static site ล้วนๆ

## วิธีใช้งาน

1. อัปโหลดไฟล์แผนเยี่ยม (ชีท `CallPlanData`) และไฟล์เยี่ยมร้านค้าจริง (`Sheet1`)
2. กด **ประมวลผลและบันทึกลง Supabase** — ระบบจะ:
   - อ่านไฟล์ทั้ง 2 ในเบราว์เซอร์ (ไม่ได้ส่งไฟล์ไปเซิร์ฟเวอร์กลาง)
   - บันทึกข้อมูลดิบทั้งหมดลง Supabase (ตาราง `upload_batches`, `visit_plans`, `actual_visits`)
   - เทียบแผนกับเยี่ยมจริง โดยจับคู่ **รหัสร้านค้า + วันที่เข้าเยี่ยม ต้องตรงกันเป๊ะ**
3. ดูผลสรุป 3 หมวด (เยี่ยมตามแผน / ยังไม่เยี่ยม / นอกแผน) แล้วกด **ดาวน์โหลดรายงาน Excel**
4. ย้อนดูรอบก่อนหน้าได้จากส่วน **ประวัติการอัปโหลด** ด้านล่าง — กด "ดูสรุป + ดาวน์โหลด"
   เพื่อดึงข้อมูลจาก Supabase มาคำนวณและสร้างรายงานซ้ำได้ทุกเมื่อ

### หมายเหตุเรื่องการจับคู่

ถ้าร้านค้ามีแผนวันที่ A แต่พนักงานไปเยี่ยมจริงวันที่ B (คนละวัน) ระบบจะนับว่า:
- แผนวันที่ A → "ยังไม่เยี่ยม" (เพราะไม่มีการเยี่ยมตรงวันที่ A)
- การเยี่ยมจริงวันที่ B → "นอกแผน" (เพราะไม่ตรงกับแผนวันไหนเลย)

ทำให้เห็นครบทั้ง 2 ด้านว่าไปผิดวันด้วย ไม่ถูกกลบไปว่า "เยี่ยมแล้ว" ทั้งที่ผิดวันที่แผนกำหนด

## โครงสร้างไฟล์

```
├── index.html          หน้าเว็บหลัก
├── style.css           สไตล์
├── app.js              โลจิกทั้งหมด (parse excel, supabase, เปรียบเทียบ, สร้างรายงาน)
├── config.js           ค่าเชื่อมต่อ Supabase (แก้ตรงนี้)
└── supabase-schema.sql SQL สำหรับสร้างตารางใน Supabase
```
